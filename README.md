# KFC Menu Prices – Modern Fast Food Menu & Price Directory

A complete, high-performance, modern, responsive, and SEO-optimized static homepage designed for the primary target keyword **"kfc menu prices"**. Built strictly using pure HTML5, CSS3, and Vanilla JavaScript.

## 🚀 Features

- **SEO & Intent Architecture**: Optimized title, meta description, H1 (*KFC Menu Prices 2026 – Full Menu With Prices*), schema structured data (WebSite, BreadcrumbList, FAQPage JSON-LD), and canonical tags.
- **Data-Driven Menu Engine**: Centralized Vanilla JS repository storing menu items with prices, calories, descriptions, categories, and vector graphics.
- **Live Search & Category Filtering**: Instant real-time search filtering across items, categories, and descriptions with zero-state handlers.
- **Original Independent Brand Identity**: Clean, editorial aesthetic utilizing `#8B1E1E` (Crimson), `#241F1F` (Dark Charcoal), `#E6A23C` (Amber Gold), and `#FFF9F2` (Cream), completely distinct from official KFC branding.
- **SVG Logos & Icons**: Text-based vector logo (`assets/logo/logo.svg`), logo mark (`assets/logo/logo-mark.svg`), and multi-format favicons.
- **Fully Responsive & Accessible**: Mobile hamburger navigation drawer, focus states, screen reader ARIA landmarks, keyboard tab navigation, and `@media (prefers-reduced-motion: reduce)` support.
- **Core Web Vitals Optimized**: Zero external framework dependencies, lightweight CSS, inline SVG food visual graphics, smooth scrolling, and zero cumulative layout shifts.

## 💻 Local Testing & Deployment

Because this project uses static HTML, CSS, and JS:
1. Simply open `index.html` in any web browser.
2. Or serve locally using Python:
   ```bash
   python -m http.server 8000
   ```
   Then navigate to `http://localhost:8000`.
